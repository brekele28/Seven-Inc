## About Project

Sistem E-Recruitment Pegawai pada Website Company Profile Seven Inc.

Project ini dikembangkan sebagai implementasi Fullstack Development dengan arsitektur monorepo yang memisahkan Frontend dan Backend dalam satu repository.
