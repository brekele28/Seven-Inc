## About Project

Sistem E-Recruitment Pegawai pada Website Company Profile Seven Inc.

Project ini dikembangkan sebagai implementasi Fullstack Development dengan arsitektur monorepo yang memisahkan Frontend dan Backend dalam satu repository.

## About Me

Halo, saya **Rois Ali Fernanda**.

Seorang **Fullstack Developer** yang berfokus pada pengembangan aplikasi web modern menggunakan React.js dan Laravel.

Repository ini menjadi bagian dari dokumentasi proses pengembangan sistem E-Recruitment untuk Seven Inc.

## Tech Stack

### Frontend

- React.js
- Tailwind CSS
- JavaScript
- React Router
- SweetAlert2

### Backend

- Laravel 12
- REST API
- MySQL
- Eloquent ORM
- JWT / Authentication
