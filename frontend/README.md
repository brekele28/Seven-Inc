# Frontend - Seven Inc

Frontend aplikasi Sistem E-Recruitment Pegawai pada Website Company Profile Seven Inc.

## Installation

Clone repository:

```bash
git clone https://github.com/brekele28/Seven-Inc.git
```

Masuk ke folder frontend:

```bash
cd Seven-Inc/frontend
```

Install dependency:

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

Aplikasi akan berjalan pada:

```text
http://localhost:5173
```
